# Keyboard Shortcut Reference

| Shortcut | Action | Scope |
| :--- | :--- | :--- |
| `Ctrl + Tab` | Next active chat window | Global |
| `Ctrl + Shift + Tab` | Previous active chat window | Global |
| `Ctrl + 1..9` | Jump directly to window index | App |
| `Ctrl + N` | Spawn new multi-account session | App |
| `Ctrl + W` | Close focused chat container | Window |
| `Ctrl + Shift + D` | Toggle developer console | Dev |
